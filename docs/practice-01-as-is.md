| Боль | Как проявляется | Кто страдает | Как ловят ошибку сейчас |
|------|-----------------|--------------|-------------------------|
|   Ручная загрузка   |   Нет истории изменений и возможности отката            |     Бизнес (нет оперативных данных), Аналитики (тратят время)        |     Ручной просмотр всех данных                   |
|    Нет версий SQL  | Всё делается прямо в базе, история не сохранается, откат невозможен |  Бизнес (Большая вероятность ошибок, потеря доверия к данным), Аналитики (Невозможность отката при ошибках) | Клиент видит ошибку в дэшборде, аналитик вручную всё проверяет |

|    Долгий time-to-insight   |       невозможность быстро выводить новые метрики, Данные теряют актуальность к моменту выхода отчета       | Бизнес (конкуренты перегоняют), Аналитики (слишком большая нагрузка)              |             Осознание упущенной выгоды, когда данные приходят слишком поздно            |
|  Разрозненные данные    | Дублирование данных, противоречия в расчётах                |   Отделы(делают лишнюю работу, не имеют общей базы), Бизнес(не может оперативно сделать общий отчёт с разных отделов)           |   Отделы сами находят ошибки в чужих отчётах                      |

## Задание B. Карта принципов DataOps

Сопоставление болей из задания A с принципами DataOps (1.7 / Манифест):

1. Ручная загрузка → Автоматизация (Orchestration) + Data as Code
2. Нет версий SQL → Data as Code + PR/Review
3. Отсутствие проверок → Качество встроено
4. Слабый lineage → Observability
5. Долгий time-to-insight → Малые изменения + Автоматизация
6. Разрозненные данные → Владение (ownership)+ Коллаборация

## Задание C. Сравнение DevOps / DataOps / MLOps

**Бизнес-кейс:** Интернет-магазин.

| Область | Что относится к кейсу | Инструменты / Практики |
|---------|----------------------|------------------------|
| **DevOps** | Сайт магазина, API заказов, корзина | Docker, Kubernetes, CI/CD для кода |
| **DataOps** | контроль freshness, Витрины данных, пайплайны загрузки заказов, отчеты | Airflow, dbt, SQL, Git, тесты данных |
| **MLOps** | Рекомендательная система "С этим товаром покупают" | MLflow, Feature Store, мониторинг модели |
