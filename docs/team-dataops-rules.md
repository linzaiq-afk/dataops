## Наши правила

1. Неправим prod SQL без PR.

2. Перед деплоем проверяем данные на null, дубликаты и отрицательные значения.                               

3. Не вносим правки на проде.

4. Спорные вопросы по метрикам и логике решаем на общем созвоне, а не в личных сообщениях.

5.  После завершения задачи мы описываем пайплайн и метрики в README или отдельном файле в репозитории.
